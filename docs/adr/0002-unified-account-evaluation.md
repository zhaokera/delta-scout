# ADR 0002：全账号统一评估与 M7 可选品质标签

- 状态：已采用
- 日期：2026-08-01
- 决策者：项目维护者与使用者

## 背景

此前准入要求账号必须包含 M7「棱镜攻势」极品 S/A/B/C 或优品 S，三个采集器也从 M7 条件入口开始。这个设计会在评分前永久丢弃没有 M7、M7 品质较低或备注没有写清 M7 的账号，即使这些账号拥有更高价值的角色红皮、巨浪、资产和更安全的交易条件。它还会让 M7 在“采集范围、硬筛选和价值评分”三个阶段重复放大。

目标是让所有符合购买边界的账号在同一候选集合中比较，M7 继续清晰展示，但不再拥有隐形保送或一票否决权。

## 决策

1. 合格候选的硬条件为 QQ、官服、已知价格在 ¥1,900–¥4,000（含边界），并同时拥有骇爪-维什戴尔与露娜-黑天际线。任一硬条件未知或只证明一款指定红皮进入待人工核验；微信、明确非官服、已知价格位于区间外或明确缺少指定红皮进入淘汰。M7 状态和品质不参与分类。
2. M7 保留为品质标签和账号价值的一部分。账号价值 100 分分配为 M7 15、已识别角色红皮 30、巨浪 20、价格 25、资产 10。M7 极品 S/A/B/C 分别为 12/10/8/6 分，优品 S 为 5 分，可信珠光、炫彩或糖果模板额外 3 分且不叠加，总计不超过 15 分。
3. 置信度不再依赖 M7 才能达到高水平。M7 证据最多贡献 10 分，其余权重覆盖登录平台、区服、价格、安全证据、资产以及红皮/巨浪信息；没有 M7 但其它证据完整的账号仍可达到 90 分。
4. 三个平台都优先使用平台自己的价格与双指定红皮 AND/ALL 筛选。交易猫目录 HTML 只证明页面结构可识别，正式列表从 MTop 第 1 页开始；其 `searchCondition` 同时使用价格 `1900,4000` 和平台公开的“干员外观多选”条件 `selling_point_7322805066952352771`，后者要求“骇爪-维什戴尔”与“露娜-黑·天际线”同时存在。螃蟹的公开查询同时使用页面定义的 `filterDTOList` 价格项 `[1900,4000]`，以及“干员皮肤”属性 `1037114` 的“全部满足”项：骇爪维什戴尔 `174203185348623`、露娜黑天际线 `161525538259004`，并以 `filterType: 1`、`isAll: true` 表达 AND；分页保留服务端 `pageToken` 并递增 `pageIndex`，重复游标不代表结束，空列表或游标消失才是自然末页。盼之由浏览器把最小价和最大价分别设为 `1900`、`4000`，并对“特战干员外观”字段 `22858` 选择两个指定选项且使用 `ALL / 全部都要有`，滚动到连续两次无新增后提交可见卡片快照。服务端仍对所有结果做同区间和必选外观二次校验，防止平台置顶广告或异常响应带入越界或缺项商品。
5. 交易猫浏览器刷新只接受三角洲行动、QQ、账号目录，且 `activeFilterLabels` 必须精确等于 `["1900-4000", "骇爪-维什戴尔", "露娜-黑·天际线"]`。任何 M7、实名或其它额外商品属性筛选都会拒绝发布，避免采集层形成未声明的隐藏硬门槛。

## 结果与取舍

### 正面结果

- 没有 M7、优品 A/B/C、品质未知或 M7 证据冲突的账号可以凭红皮、巨浪、价格、资产和安全条件公平参与排名。
- M7 仍有明确品质标签、稀有模板标签和可解释分值，但最高只占账号价值的 15%。
- 红皮权重提高到 30%，更接近全账号资产比较，而不是单皮肤筛选器。
- 采集入口、准入、置信度和评分使用同一语义，避免界面宣称统一评分但底层只采 M7 账号。

### 负面结果

- 原生价格筛选显著减少分页和逐条详情耗时，但完整刷新时间仍取决于实际区间内商品数量；现有限速、详情熔断、旧快照保留和安全上限继续生效。
- 盼之的列表接口带签名与浏览器风控，后端不猜测或伪造接口调用；完整覆盖依赖 Codex 浏览器中用户可见的原生筛选和滚动快照，因此需要浏览器可用。
- 历史候选排名会发生变化，且旧快照需要在应用启动时按新规则重算。

### 中性影响

- M7 精确证据解析、品质筛选、珠光/炫彩/糖果标签和人工“M7 不值”反馈仍保留；它们只影响展示与排序。
- 平台均衡 Top 30、全局 Top 30、人工淘汰、风险等级和购买前人工验号流程不变。

## 备选方案

1. 保留 M7 硬门槛，仅继续降权：拒绝。它仍会在评分前丢弃其它高价值账号，无法实现统一评估。
2. 只改分类，不改采集入口：拒绝。快照仍然是 M7 预筛后的子集，会造成“伪统一评估”。
3. 完全删除 M7 解析和评分：拒绝。M7 品质与稀有模板仍是用户关心的可解释资产信息。
4. 为盼之猜测签名或绕过浏览器验证：拒绝。改用页面原生筛选、可见卡片和严格的本地快照接口，既保留完整滚动覆盖，也不读取或导出登录凭据。
