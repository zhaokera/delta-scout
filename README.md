# 三角洲账号候选台

本地运行的《三角洲行动》账号比较工具。它读取交易猫、盼之代售和螃蟹账号的公开商品页面，严格筛选：

- QQ 官服
- M7「棱镜攻势」明确为极品
- 价格不超过 ¥6,000

候选台同时展示角色红皮、M7 品质、巨浪、总资产、哈夫币、实名状态、包赔信息、原文证据、置信度、扫描稳定性和可解释推荐分。默认候选池兼顾三个平台，也可以切换为完全按分数排序的跨平台总榜。

## 启动

环境要求：Node.js 24+、pnpm。

```bash
pnpm install
pnpm dev
```

随后在浏览器打开：

```text
http://127.0.0.1:4311/
```

前端开发服务运行在 `4311`，本地 API 运行在 `4310`。点击页面右上角的“刷新公开数据”会在后台启动采集；页面会显示当前平台、阶段、页数、商品数和详情数，无需一直阻塞等待请求返回。

## 常用命令

```bash
pnpm test

pnpm build
```

生产构建输出到 `dist/` 和 `dist-server/`。

## 三平台状态

| 平台 | 当前公开采集方式 | 受限时的处理 |
| --- | --- | --- |
| 交易猫 | 从公开入口发现三角洲目录 | 遇到 CAPTCHA 时标记“验证码阻塞”，不绕过 |
| 盼之代售 | 读取公开列表和商品详情 | 页面结构变化时保留旧快照并标记来源异常 |
| 螃蟹账号 | 首页确认三角洲目录后，调用页面自身使用的公开只读 JSON 商品查询 | 接口或字段结构变化时保留旧快照并标记来源异常 |

平台页面会变化。交易猫适配器只使用已验证的公开目录、详情和分页请求；盼之适配器仅从校验过的 exact 结果页 URL 确定性生成 `page=N+1`，并只解析同站详情链接。螃蟹账号仅使用已经从其公开页面代码确认、无需认证的商品查询请求，不尝试相邻路径或交易接口。

## 数据与分类规则

- 每个来源会持续读取到平台自然末页；100 页、2,000 条唯一摘要和 500 个详情是防止异常循环的安全上限，不是正常分页上限。
- 螃蟹每页最多 16 条，并沿公开 `pageToken` 读取到自然末页。平台均衡候选池每个平台最多展示推荐分最高的 10 条；“全局 Top 30”不设平台配额，直接从所有新鲜合格账号中取推荐分最高的 30 条。完整视图保留全部实际商品，不伪造或重复。
- 同一来源请求间隔至少 2 秒，单次请求 15 秒超时并最多重试一次。
- 商品必须同时证明 QQ、官服、价格不超过 ¥6,000、M7 棱镜攻势极品，才进入“合格候选”。
- M7 的“棱镜攻势”和“极品”必须出现在同一条证据记录中，禁止跨字段拼接。
- 优品、超预算、微信或明确非官服会进入“已淘汰”；证据不完整或互相冲突会进入“待人工核验”。
- 推荐分满分 100：安全信息 30、皮肤价值 30、价格 20、可核验资产 10、数据置信度 10。皮肤价值明确计入 M7 品质 S/A/B/C、已识别角色红皮数和巨浪；价格与资产使用当前新鲜合格候选集合内的稳定秩百分位，避免极端值拉歪整批结果。
- 每轮扫描会记录来源结果和商品物质指纹，本地只保留最近 50 轮。只有来源连续两轮都完整扫描成功、且账号物质字段不变时才标记“连续稳定”；首次出现、发生变化或任一轮来源不完整会分别标记为首次、变化或待观测。
- 刷新 API 异步返回。`success` 会发布新快照；`partial` 会发布本轮可用来源并明确展示异常来源；`failed` 不覆盖现有快照。某来源受阻或失败时保留其旧商品供完整视图核验，但旧商品不参与当前候选池和集合相对评分。前端在刷新或进度查询失败时也不会清空当前候选与已选详情。
- 单条详情异常会把该来源标为 `partial`；同一来源连续 3 条详情均受阻或失败时立即停止该来源并保留旧快照，避免验证码或结构异常被误记为完整成功，也避免继续请求加重平台风控。
- 超过 24 小时未成功更新的来源会显示为陈旧。

本地快照、最近 50 轮扫描历史和稳定性观察保存在 `data/scout.sqlite`，该目录已从 Git 排除。

## 安全边界

- 工具只读取无需登录即可访问的公开商品信息。
- 不保存账号、密码、Cookie、认证/会话 Token、验证码或支付信息，也不复用浏览器登录态。
- 螃蟹公开响应中的 `pageToken` 只在单次刷新内存中作为分页游标，刷新结束即丢弃，不写入 SQLite、日志、证据或配置。
- 不处理或绕过 CAPTCHA，不逆向未公开接口。
- 三个平台保持串行、限速的只读采集；遇到 CAPTCHA、页面结构变化或公开接口异常时记录为 blocked/partial/failed，不尝试规避平台限制。
- 不自动下单、不联系卖家、不代替用户登录或付款。
- 页面中的解析结果仅用于缩小候选范围。购买前必须回到原平台重新验号，重点确认 M7 品质、区服、二次实名、找回包赔、封禁记录及商品是否仍在售。
